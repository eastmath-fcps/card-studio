  2. Open the Share menu and choose Add to Home Screen.
  3. If offered, leave Open as Web App on, then tap Add.

The browser could not open the installation prompt. You can look for Install in the browser menu, or try again on your next visit.

Save your layout before opening the installed app. Import your spreadsheet again in the new window. After the footer says “Offline ready,” you can reopen the app without a connection. New Google Fonts still need internet access.

A quick guide

  1. Import. Choose a CSV or Excel file with unique column headings in the first row. Select the worksheet if needed.
  2. Design. Add text, images, and shapes. Select a text box and click a merge field to insert it. For example, <<LastName>>, <<FirstName>> .
  3. Save. Save named layouts in this browser. Export JSON files for backups and sharing. Images are embedded; imported data is excluded.
  4. Print. Choose your paper stock, review the sheet preview, test on plain paper, then print at 100% on the matching paper size. Turn off headers and footers and enable background graphics.

Install Card Studio

Choose Install app in the footer when it appears. Your browser decides when installation is available; the button may not appear immediately or if the app is already installed.

On iPhone or iPad, open this page in Safari and choose Share → Add to Home Screen. Leave Open as Web App on if offered. In Safari on Mac, choose File → Add to Dock.

Once the footer says Offline ready, you can reopen Card Studio, import CSV or Excel files, design, save, and print without a connection. Google Fonts work offline only when the needed styles and characters are cached; use system or imported fonts for dependable offline work. Browser storage can be cleared or evicted, so keep exported layouts and original font files as backups.

When Update available appears, you can keep working or choose it to update. The app saves unsaved layout changes before an approved reload and reopens that layout afterward. Import your spreadsheet again after reloading. Close other Card Studio windows before applying the update.

Keyboard shortcuts

Arrow keys: move 0.01 in - Shift + arrows: move 0.1 in
Delete: remove object - Ctrl/Cmd + D: duplicate object
Ctrl/Cmd + Z: undo - Ctrl/Cmd + Shift + Z: redo
Ctrl/Cmd + S: save layout - Escape: deselect

Use Chrome or Edge for the most consistent printing. Google Fonts load from Google when needed; spreadsheet contents are not sent to Google. The Excel reader library is bundled with the app.

A quick guide

  1. Import. Choose a CSV or Excel file with unique column headings in the first row. Select the worksheet if needed.
  2. Design. Add text, images, and shapes. Select a text box and click a merge field to insert it. For example, <<LastName>>, <<FirstName>> .
  3. Save. Save named layouts in this browser. Export JSON files for backups and sharing. Images are embedded; spreadsheet rows are excluded.
  4. Print. Review the sheet preview, test on plain paper, then print at 100% on Letter paper. Turn off headers and footers and enable background graphics.

Keyboard shortcuts

Arrow keys: move 0.01 in - Shift + arrows: move 0.1 in
Delete: remove object - Ctrl/Cmd + D: duplicate object
Ctrl/Cmd + Z: undo - Ctrl/Cmd + Shift + Z: redo
Ctrl/Cmd + S: save layout - Escape: deselect

Use Chrome or Edge for the most consistent printing. Google Fonts and the Excel reader load from external services when needed; spreadsheet contents are not sent to those services. Network restrictions may block these resources.
